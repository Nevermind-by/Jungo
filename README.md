# Jungo

**Нативный локальный Kanban для macOS 26 Tahoe и новее.**

Jungo — персональная доска задач с нативным SwiftUI-интерфейсом и локальным хранением через SwiftData. Аккаунт, backend и интернет для основной работы не нужны.

## Возможности

- Несколько досок: создание, переименование, переключение, сохранение выбора и безопасное удаление.
- Колонки: создание, переименование, изменение порядка и удаление с переносом карточек в соседнюю колонку.
- Карточки: заголовок, описание, метки, приоритет, срок выполнения и чек-листы.
- Перетаскивание карточек между колонками и перестановка внутри колонки.
- Поиск, фильтр по приоритету и просроченным задачам.
- Корзина задач: удаление с возможностью восстановления и отдельное подтверждение окончательного удаления.
- Локальное хранение SwiftData, системная светлая/тёмная тема, контекстные меню и клавиатурные команды.
- JSON-экспорт и импорт как дополнительных досок без перезаписи существующих данных; архив включает сроки, метки, чек-листы и состояние корзины.
- Понятные сообщения об ошибках сохранения, импорта и экспорта.
- Генерация собственной иконки Jungo и скрипт сборки приложения.
- Unit-тесты для правил порядка и нормализации меток.

## Запуск

Требования: macOS 26 Tahoe+, Swift 6 toolchain и Xcode Command Line Tools.

    swift test
    swift run Jungo

Собрать и открыть локальное приложение:

    Scripts/run-app.sh

Собрать только приложение:

    Scripts/build-app.sh

Иконка создаётся локально из Swift-скрипта Scripts/generate-icon.swift, поэтому внешние изображения и сетевые зависимости не нужны. Development bundle подписывается ad-hoc и не является notarized-релизом.

## Релизная сборка

Для распространения вне Mac App Store необходимы Apple Developer account, сертификат Developer ID Application и сохранённый профиль notarytool. После настройки:

    security find-identity -v -p codesigning
    xcrun notarytool store-credentials "JungoNotary" --apple-id "APPLE_ID" --team-id "TEAM_ID" --password "APP_SPECIFIC_PASSWORD"
    DEVELOPER_ID="Developer ID Application: Your Name (TEAMID)" NOTARY_PROFILE="JungoNotary" Scripts/package-release.sh

Скрипт подписывает приложение с hardened runtime, проверяет подпись, отправляет архив на нотариальное заверение, прикрепляет ticket и создаёт dist/Jungo-macOS.zip. Реальную подпись и нотариализацию можно выполнить только с действующими учётными данными разработчика.

## Локальные данные и резервная копия

Jungo хранит данные на этом Mac. Импорт JSON создаёт копии досок с новыми идентификаторами, не заменяя текущие данные. Задачи в корзине включаются в резервную копию. Экспортируй данные перед удалением или переустановкой приложения.
