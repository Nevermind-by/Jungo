# Jungo

**Нативный локальный Kanban для macOS 26 Tahoe и новее.**

Jungo — персональная доска задач с нативным SwiftUI-интерфейсом и локальным хранением через SwiftData. Аккаунт, backend и интернет для основной работы не нужны.

## Реализованные возможности

- Несколько досок: создание, переименование, переключение и безопасное удаление с подтверждением.
- Колонки: создание, переименование, изменение порядка и удаление с переносом карточек в соседнюю колонку.
- Карточки: создание, редактирование заголовка и описания, приоритет и срок, безопасное удаление.
- Перетаскивание карточек между колонками и перестановка внутри колонки.
- Поиск по названию и описанию, фильтр по приоритету и по просроченным задачам.
- Локальное хранение SwiftData; начальные данные создаются только для пустого хранилища.
- Экспорт всех данных в JSON и импорт JSON как дополнительных досок без перезаписи существующих данных.
- Системная светлая/тёмная тема, нативные контекстные меню и горячая клавиша создания задачи.
- Показ ошибок сохранения, импорта и экспорта в интерфейсе.
- Unit-тесты чистых функций порядка и перемещения карточек.

## Запуск и проверки

Требования: macOS 26 Tahoe+, Swift 6 toolchain и Xcode Command Line Tools.

    swift test
    swift run Jungo

Эти команды пока не запускались в этой среде. Перед использованием на Mac нужно выполнить обе команды и проверить сценарии из docs/DEVELOPMENT.md.

Текущий формат — Swift Package Manager executable для разработки. Для релизного распространения отдельно потребуются .app bundle, иконка, подпись и выбранный канал доставки.

## Локальные данные и резервная копия

Данные остаются в локальном хранилище SwiftData. Через меню доски или боковую панель можно экспортировать JSON-архив. Импорт добавляет копии досок с новыми идентификаторами, поэтому не перезаписывает текущие доски. Экспорт храните в безопасном месте: приложение не отправляет данные в облако.

## Принципы

- **Native first:** SwiftUI и системные паттерны macOS.
- **Local first:** SwiftData без облачной синхронизации.
- **Safe by default:** подтверждение разрушительных действий и импорт без замены существующих данных.
- **Keyboard-friendly:** горячая клавиша для создания задачи.
- **Testable domain:** правила порядка вынесены в отдельный модуль и покрыты unit-тестами.
