# Jungo

**Нативный локальный Kanban для macOS 26 Tahoe и новее.**

Jungo — персональная доска задач с нативным SwiftUI-интерфейсом и локальным хранением через SwiftData. Аккаунт, backend и интернет для основной работы не нужны.

## Реализованные возможности

- Несколько досок: создание, переименование, переключение, сохранение выбора и безопасное удаление.
- Колонки: создание, переименование, изменение порядка и удаление с переносом карточек в соседнюю колонку.
- Карточки: заголовок, описание, метки, приоритет, срок выполнения и чек-лист.
- Перетаскивание карточек между колонками и перестановка внутри колонки.
- Поиск по названию и описанию, фильтр по приоритету и просроченным задачам.
- Локальное хранение SwiftData; начальные данные создаются только для пустого хранилища.
- Экспорт всех данных в JSON и импорт JSON как дополнительных досок без перезаписи существующих данных; архив включает метки, сроки и чек-листы.
- Системная светлая/тёмная тема, нативные контекстные меню и горячая клавиша создания задачи.
- Показ ошибок сохранения, импорта и экспорта в интерфейсе.
- Unit-тесты правил порядка карточек и нормализации меток.

## Запуск и проверки

Требования: macOS 26 Tahoe+, Swift 6 toolchain и Xcode Command Line Tools.

    swift test
    swift run Jungo

Для создания запускаемого bundle приложения:

    Scripts/build-app.sh
    open dist/Jungo.app

Или собрать и сразу запустить:

    Scripts/run-app.sh

Скрипт создаёт development bundle с ad-hoc подписью. Это не notarized-релиз и пока не содержит пользовательской иконки. Сборку и запуск нужно проверить на Mac.

## Метки и чек-листы

Метки вводятся через запятую в редакторе задачи. Пустые метки и дубликаты без учёта регистра игнорируются. В чек-листе можно добавлять пункты, отмечать их выполненными и удалять. Удаление задачи или доски также удаляет связанные пункты чек-листа.

## Локальные данные и резервная копия

Данные остаются в локальном хранилище SwiftData. JSON-импорт создаёт копии досок с новыми идентификаторами, не заменяя текущие данные. Экспорт храните в безопасном месте: приложение не отправляет данные в облако.

## Принципы

- **Native first:** SwiftUI и системные паттерны macOS.
- **Local first:** SwiftData без облачной синхронизации.
- **Safe by default:** подтверждение разрушительных действий и импорт без замены существующих данных.
- **Keyboard-friendly:** горячая клавиша для создания задачи.
- **Testable domain:** правила порядка и разбора меток вынесены в JungoCore и покрыты unit-тестами.
