# Jungo

**Нативный локальный Kanban для macOS 26 Tahoe и новее.**

Jungo помогает вести личные задачи на Mac: несколько досок, колонки, карточки, сроки, приоритеты, метки и чек-листы — без аккаунта, backend и обязательного подключения к сети.

<p align="center">
  <strong>Local-first · Native SwiftUI · SwiftData · macOS 26+</strong>
</p>

## Возможности

- **Доски и колонки:** несколько досок, архивирование, восстановление, дублирование и настройка структуры.
- **Задачи:** заголовок, Markdown-описание с предпросмотром, приоритет, срок, метки и чек-лист.
- **Быстрое управление:** drag-and-drop, клавиатурные действия, Undo/Redo и быстрый ввод.
- **Поиск и фильтры:** поиск по задачам и меткам, фильтрация по приоритету, меткам и просрочке, сохранённые фильтры.
- **Корзина:** восстановление задач и отдельное окончательное удаление.
- **Резервные копии:** JSON-экспорт и импорт как дополнительных досок, без перезаписи текущих данных.
- **Локальный Vault:** выбор расположения SwiftData-хранилища, безопасный перенос и проверка доступности/целостности базы.
- **Нативный интерфейс:** системные темы macOS, адаптивные окна, Liquid Glass на подходящих интерактивных поверхностях и учёт настроек доступности.
- **Быстрый доступ:** меню-бар, глобальное сочетание `Cmd+Option+Space` и сочетание `Cmd+Option+N` внутри приложения.

## Требования

- macOS 26 Tahoe или новее.
- Для сборки из исходников — Swift 6 toolchain и Xcode Command Line Tools.

## Запуск из исходников

Клонируй репозиторий и выполни:

```bash
swift test
swift run Jungo
```

Собрать и открыть приложение:

```bash
Scripts/run-app.sh
```

Только собрать `.app`:

```bash
Scripts/build-app.sh
```

Скрипт генерирует иконку, собирает release executable и упаковывает локальный development bundle. Версия по умолчанию — `0.1.0`, build number — `1`. Их можно переопределить:

```bash
JUNGO_VERSION="0.1.0" JUNGO_BUILD_NUMBER="1" Scripts/build-app.sh
```

Development bundle подписывается ad-hoc. Это удобно для локального запуска, но не является Developer ID-подписанной или notarized-сборкой для распространения на чужих Mac.

## Данные и резервное копирование

Jungo хранит рабочие данные локально через SwiftData. В настройках приложения можно выбрать папку активного Vault. При недоступности выбранного хранилища приложение не должно молча подменять его новой пустой базой.

JSON-экспорт создаёт отдельный файл резервной копии. Импорт добавляет копии досок с новыми идентификаторами и не заменяет существующие данные. Перед рискованными операциями рекомендуется сделать экспорт.

## Проверки и статус

GitHub Actions на macOS 26 запускает `swift test`, собирает development app bundle и проверяет метаданные приложения и иконку. Последняя проверка текущего кода перед подготовкой документации: [CI run #186](https://github.com/Nevermind-by/Jungo/actions/runs/41058799530) — успешно.

Последний интерфейсный фикс Quick Add включён в [PR #67](https://github.com/Nevermind-by/Jungo/pull/67), который слит в `main`. После этого пользователь подтвердил корректное отображение Quick Add при локальном запуске.

CI не заменяет ручные проверки миграций SwiftData, переноса Vault, восстановления после аварийного завершения, VoiceOver и сложных сценариев импорта. Их статус ведётся отдельно в чек-листах; не отмечай их пройденными без фактического теста.

## Границы MVP

Jungo рассчитан прежде всего на личное локальное использование на одном Mac. В MVP не входят облачная синхронизация, аккаунты, backend, совместная работа, интеграции, вложения и расширенная панель Markdown-форматирования.

Репозиторий и GitHub Releases используются для исходного кода и истории версий. Проект не обещает готовый подписанный/notarized бинарный дистрибутив. Для распространения готового приложения за пределами собственного Mac отдельно потребуются Developer ID signing и notarization.
