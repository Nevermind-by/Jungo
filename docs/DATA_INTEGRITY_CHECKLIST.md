# Проверка целостности данных Jungo

Этот checklist — ручной acceptance gate перед повседневным использованием. CI подтверждает unit-тесты и сборку, но не заменяет проверку SwiftData, интерфейса и файлового доступа на реальном Mac.

## Vault

### Перенос хранилища
- [ ] Перенести непустую базу в пустую папку.
- [ ] Сверить количество досок, колонок, задач и пунктов чек-листа до и после переноса.
- [ ] Сверить связи: колонка → доска, задача → колонка, пункт чек-листа → задача.
- [ ] Проверить сохранение архивных досок, корзины, меток, приоритетов, сроков и чек-листов.
- [ ] Убедиться, что исходная база остаётся доступной до успешной проверки новой.
- [ ] Повторить перенос в папку с существующим Jungo.store и SQLite sidecar-файлами; ничего из существующего не должно измениться.
- [ ] Проверить ошибку записи: исходное хранилище должно остаться активным.

### Восстановление доступа
- [ ] Выбрать папку с корректным Jungo.store; доступ восстанавливается после проверки базы.
- [ ] Выбрать папку без Jungo.store; bookmark/path не меняются.
- [ ] Выбрать пустой, посторонний или повреждённый файл Jungo.store; он не становится активным хранилищем.
- [ ] Проверить базу с нарушенными ссылками; bookmark не сохраняется.
- [ ] Отключить внешний диск, перезапустить приложение и убедиться, что Jungo не переключается молча на пустую базу.
- [ ] Подключить диск снова и повторно восстановить доступ.

## Импорт и экспорт
- [ ] Экспортировать доску со всеми типами данных; JSON открывается и содержит ожидаемые записи.
- [ ] Импортировать архив в непустую базу; существующие записи не перезаписываются.
- [ ] Импортировать один архив дважды; обе копии независимы и получают новые ID.
- [ ] Сверить связи импортированных колонок, задач и пунктов чек-листа внутри каждой копии.
- [ ] Проверить сохранение неизвестного priorityRawValue, archive status, due date, labels, trash и checklist state.
- [ ] Импортировать архив старого формата без необязательных полей.
- [ ] Импортировать архив с неверной версией, пустыми названиями, дублирующимися ID, повреждёнными ссылками и некорректным JSON; после каждой ошибки не должно появляться частичных записей.
- [ ] Убедиться, что ошибка импорта не откатывает несохранённые изменения основного UI-контекста.
- [ ] Экспортировать поверх существующего файла и проверить, что файл заменяется целиком.

## Undo / Redo

Проверять обычные сохранённые операции через стандартные команды меню Edit и системные сочетания Undo/Redo.

- [ ] Изменить заголовок и описание задачи; Undo возвращает прежние значения, Redo применяет новые.
- [ ] Изменить приоритет, срок и метки; Undo/Redo восстанавливают состояние.
- [ ] Переместить задачу между колонками; Undo/Redo восстанавливают колонку и позицию.
- [ ] Изменить порядок задач внутри колонки; Undo/Redo восстанавливают порядок.
- [ ] Переместить задачу в корзину и восстановить её; проверить Undo/Redo для каждого действия.
- [ ] Выполнить несколько разных изменений подряд и проверить последовательность Undo, затем Redo.
- [ ] После Undo/Redo проверить, что задача и её checklist items остаются связаны корректно.
- [ ] Проверить, что Undo/Redo не меняют данные другой доски.

### Необратимые операции и каскады
- [ ] Удалить доску через подтверждение; проверить, что её колонки, задачи и пункты чек-листа удалены и не осталось осиротевших записей. UI явно предупреждает, что удаление доски нельзя отменить — Undo для этой операции не обещается.
- [ ] Удалить колонку; убедиться, что её задачи перенесены в первую оставшуюся колонку и порядок сохранён.
- [ ] Удалить задачу навсегда из корзины; её checklist items также удаляются.
- [ ] Повторно открыть приложение и убедиться, что результат необратимых операций сохранён.

## Перезапуск и восстановление
- [ ] Создать и изменить данные, штатно закрыть приложение, открыть снова и сверить данные.
- [ ] Повторить с выбранным внешним Vault.
- [ ] Проверить повторный запуск после принудительного завершения приложения после успешного сохранения.
- [ ] Убедиться, что отсутствие или недоступность выбранного Vault не приводит к созданию пустой базы по умолчанию.

## Статус автоматического покрытия
- JungoCore: unit-тесты валидации JSON-архивов, codec и pure import plan (remapping ID, внутренние ссылки, сохранение полей, независимые повторные планы).
- GitHub Actions: `swift test`, development app bundle, Info.plist, executable и AppIcon проходят на macOS 26.
- SwiftData Undo/Redo integration tests не включены: экспериментальный SwiftPM test runner падал с `signal 5`, в том числе после сериализации suite. Автоматическое покрытие SwiftData Undo/Redo не заявляется.
- Реальный запуск, визуальная проверка и сценарии выше остаются ручным acceptance на macOS.
