# Проверка целостности данных Jungo

Документ фиксирует сценарии, которые должны быть пройдены перед production-релизом. Автоматическая компиляция и unit-тесты не заменяют эти проверки на macOS.

## Vault

### Перенос хранилища

- [ ] Перенести непустую базу в пустую папку.
- [ ] Сверить количество досок, колонок, задач и пунктов чек-листа до и после переноса.
- [ ] Сверить все связи: колонка → доска, задача → колонка, пункт чек-листа → задача.
- [ ] Проверить сохранение архивных досок, корзины, меток, приоритетов и сроков.
- [ ] Убедиться, что исходная база остаётся доступной до успешной проверки новой.
- [ ] Повторить перенос в папку, где уже есть Jungo.store; существующие файлы не должны измениться.
- [ ] Повторить перенос при ошибке записи; исходное хранилище должно остаться активным.

### Восстановление доступа

- [ ] Выбрать папку с корректной базой Jungo.store; после проверки доступ восстанавливается.
- [ ] Выбрать папку без Jungo.store; настройки bookmark/path не меняются.
- [ ] Выбрать папку с посторонним или повреждённым файлом Jungo.store; он не должен становиться активным хранилищем.
- [ ] Выбрать базу с нарушенными ссылками; восстановление должно завершиться ошибкой до сохранения bookmark.
- [ ] Отключить внешний диск после восстановления, перезапустить приложение и убедиться, что Jungo не переключается молча на пустую базу.
- [ ] Подключить диск снова и проверить повторное восстановление доступа.

## Импорт и экспорт

- [ ] Экспортировать доску со всеми типами данных и проверить JSON.
- [ ] Импортировать архив в непустую базу; существующие записи не должны перезаписываться.
- [ ] Повторно импортировать тот же архив; новые сущности получают новые ID, связи внутри каждой копии остаются корректными.
- [ ] Проверить сохранение неизвестного priorityRawValue при export/import.
- [ ] Импортировать архив без необязательных полей старой версии.
- [ ] Импортировать архив с неверной версией, пустыми названиями, дубликатами ID и оборванными ссылками; частичных записей после ошибки быть не должно.

## Undo / Redo

- [ ] Удалить доску с колонками, задачами и чек-листами; Undo восстанавливает весь граф.
- [ ] Повторить удаление через Redo.
- [ ] Переместить задачу между колонками; Undo и Redo восстанавливают колонку и позицию.
- [ ] Переместить задачу в корзину; Undo возвращает её, Redo снова помещает в корзину.
- [ ] Выполнить несколько разных изменений подряд и проверить последовательность Undo/Redo.
- [ ] Проверить стандартные команды меню macOS и сочетания клавиш.

## Перезапуск и восстановление

- [ ] Создать и изменить данные, закрыть приложение штатно, открыть снова и сверить данные.
- [ ] Повторить с выбранным внешним Vault.
- [ ] Проверить восстановление после принудительного завершения приложения после сохранения.
- [ ] Убедиться, что отсутствие или недоступность выбранного Vault не приводит к созданию пустой базы по умолчанию.

## Статус

- Автоматически: unit-тесты JungoCore и проверки формата/валидации архива.
- В работе: безопасное восстановление доступа к Vault теперь сначала открывает существующую базу и проверяет целостность связей, а bookmark сохраняется только после успешной проверки.
- Не подтверждено: фактический запуск всех сценариев на macOS.
- Undo/Redo: прямой SwiftData integration suite пока не запускается в SwiftPM test runner (падение signal 5); автоматическое покрытие не заявляется.
