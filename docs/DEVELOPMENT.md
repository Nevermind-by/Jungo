# Разработка и Git workflow

## Требования

- macOS 26 Tahoe или новее.
- Xcode Command Line Tools и Swift 6 toolchain.
- Для личного использования достаточно локальной development-сборки.
- Только если понадобится делиться готовым приложением через GitHub Releases: Apple Developer account, Developer ID Application certificate и notarytool keychain profile.

## Локальные команды

    swift test
    swift run Jungo
    Scripts/build-app.sh
    Scripts/run-app.sh

Scripts/build-app.sh генерирует иконку, собирает release executable и создаёт development bundle с ad-hoc подписью. Это локальная сборка, не notarized-релиз. Версия по умолчанию — 0.1.0, build number — 1. Их можно переопределить через `JUNGO_VERSION` и `JUNGO_BUILD_NUMBER`; версия должна быть в формате MAJOR.MINOR.PATCH, номер сборки — положительным целым числом.

Пример сборки с другой версией:

    JUNGO_VERSION="1.0.0" JUNGO_BUILD_NUMBER="12" Scripts/build-app.sh

## Необязательная подпись для публикации в GitHub Releases

Этот раздел не нужен для повседневного личного использования. Подписанная и notarized-сборка имеет смысл только если Jungo будет распространяться за пределами собственного Mac. Mac App Store не является целью проекта.

## Настройка релизной подписи

1. Установить Developer ID Application certificate в Keychain.
2. Проверить доступную identity:

       security find-identity -v -p codesigning

3. Сохранить credentials для нотариализации в Keychain profile:

       xcrun notarytool store-credentials "JungoNotary" --apple-id "APPLE_ID" --team-id "TEAM_ID" --password "APP_SPECIFIC_PASSWORD"

4. Собрать подписанный и notarized ZIP:

       JUNGO_VERSION="1.0.0" JUNGO_BUILD_NUMBER="12" DEVELOPER_ID="Developer ID Application: Your Name (TEAMID)" NOTARY_PROFILE="JungoNotary" Scripts/package-release.sh

Не сохраняй Apple ID пароль, app-specific password, сертификаты или другие секреты в репозитории. Скрипт проверяет подпись, отправляет архив на notarization, прикрепляет ticket и создаёт dist/Jungo-1.0.0-macOS.zip (имя по умолчанию содержит версию).

## GitHub Actions

.github/workflows/macos-ci.yml запускает swift test, собирает .app на macOS 26 и проверяет Info.plist, исполняемый файл и иконку. CI не выполняет подпись Developer ID или notarization.

## Правило веток

Каждый функциональный блок — отдельная ветка. Именование: feature/<short-name>, fix/<short-name>, docs/<short-name>.

## Чек-лист ручной проверки

- [ ] Создание/переименование доски, дублирование активной и архивной доски; проверить новые ID, порядок колонок, метки, сроки, сброс чек-листов и исключение задач из корзины.
- [ ] Проверить пустое состояние без досок, без колонок, пустую колонку и отсутствие совпадений после фильтрации.
- [ ] Создание, быстрое добавление, редактирование, дублирование и перемещение задачи; проверить, что копия появляется сразу после оригинала и чек-лист сбрасывает отметки.
- [ ] Проверить Правка → Отменить/Повторить для изменения названия, перемещения задачи, корзины и восстановления.
- [ ] Markdown-просмотр отображает жирный текст, списки и ссылки без изменения исходного текста.
- [ ] Удаление задачи в корзину, восстановление, окончательное удаление.
- [ ] После окончательного удаления удаляются пункты чек-листа.
- [ ] Перетаскивание между колонками и перестановка внутри колонки.
- [ ] Удаление колонки переносит задачи.
- [ ] Метки, чек-лист, сроки и приоритет сохраняются после перезапуска.
- [ ] Цвета меток стабильны между запусками; пользовательские цвета сохраняются после перезапуска.
- [ ] Сохранить фильтр, применить его после смены доски и перезапуска; проверить переименование совпадающего фильтра и удаление.
- [ ] Фильтр по метке не влияет на сохранённые данные и сбрасывается при смене доски.
- [ ] Карточки доступны с клавиатуры; VoiceOver читает название, приоритет, срок, метки и прогресс чек-листа.
- [ ] Cmd+Option+N открывает быструю форму; задача создаётся в выбранной колонке.
- [ ] Значок Jungo в меню-баре открывает быструю форму и позволяет открыть основное окно.
- [ ] Глобальная Cmd+Option+Space открывает быструю форму, в том числе когда активно другое приложение.
- [ ] После закрытия основного окна глобальная клавиша повторно открывает Jungo и показывает быструю форму.
- [ ] Если Cmd+Option+Space занята другим приложением, меню-бар показывает понятную ошибку и позволяет повторить регистрацию; пункт быстрого добавления в меню остаётся доступен.
- [ ] Экспорт/импорт включает метки, сроки, чек-листы и корзину.
- [x] Unit-тесты валидации архива: неподдерживаемая версия, повторяющиеся ID, отсутствующие родительские записи, пустые названия.
- [x] Автоматический тест декодирования старого JSON-архива без опциональных полей.
- [ ] Импорт старого JSON-архива через UI и проверка восстановленных значений по умолчанию.
- [ ] Повреждённый JSON вызывает понятную ошибку.
- [ ] Проверка светлой/тёмной темы и VoiceOver.
- [ ] Запуск через dist/Jungo.app; иконка отображается в Finder и Dock.
- [ ] Локальная development-сборка открывается и корректно сохраняет данные на целевом Mac.
- [ ] Только если планируется публикация готовой сборки для других пользователей: подписанная/notarized сборка открывается на чистом Mac.

## Принцип

Не отмечать проверку выполненной, если команда или сценарий фактически не запускались. Статическая проверка кода не заменяет сборку и тесты на macOS.
