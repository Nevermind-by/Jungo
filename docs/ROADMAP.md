# Дорожная карта Jungo

> Срез на 2026-10-30. MVP функционально завершён; текущая задача — публикация исходного кода на GitHub. Открытые ручные проверки данных не объявляются выполненными и ведутся в отдельных checklist-документах.

## Этап 0 — Основа проекта — **Завершён**

- [x] macOS 26+, SwiftUI, SwiftData и локальный режим.
- [x] Архитектура Swift Package Manager.
- [x] Документация и Git workflow.

## Этап 1 — Kanban MVP

- [x] Несколько досок, архивирование, восстановление и дублирование.
- [x] Колонки: создание, редактирование, удаление и изменение порядка.
- [x] Задачи: создание, редактирование, дублирование и удаление.
- [x] Приоритеты, сроки, метки и чек-листы.
- [x] Drag-and-drop между колонками и внутри колонок.
- [x] Поиск, фильтры и сохранённые фильтры.
- [x] Markdown-описания с предпросмотром.
- [x] Корзина с восстановлением и окончательным удалением.
- [x] Быстрое добавление и клавиатурные команды.

## Этап 2 — Хранение и надёжность

- [x] Локальный SwiftData Vault и выбор пользовательской папки.
- [x] Перенос базы с сохранением ID и проверкой связей.
- [x] Защита от молчаливого перехода на пустую базу при недоступном Vault.
- [x] JSON codec, валидация и совместимость раннего формата.
- [x] Import plan с переназначением ID и внутренних связей.
- [x] Изолированный контекст импорта и rollback при ошибке.
- [x] Генерация иконки и скрипты сборки .app.
- [x] GitHub Actions на macOS 26.

## Этап 3 — UX и доступность (реализация в исходниках)

- [x] Системная типографика и семантические цвета.
- [x] Drop-target feedback и клавиатурные действия карточек.

- [x] Обновлённый редактор задачи и Quick Add.
