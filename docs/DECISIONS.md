# Решения и открытые вопросы

## Принятые решения

| Решение | Статус | Причина |
|---|---|---|
| Нативное приложение macOS 26+ | Принято | SwiftUI и системные паттерны macOS |
| Local-first, без аккаунта и backend | Принято | Простое личное приложение без инфраструктуры |
| SwiftData для локального хранения | Принято | Нативная persistence-модель |
| Пользовательская папка Vault | Принято | Контроль расположения базы и переносимость локальных данных |
| JSON-импорт добавляет копии досок | Принято | Не перезаписывать данные молча |
| Удаление колонки переносит карточки | Принято | Защита от случайной потери задач |
| Удаление задачи сначала в корзину | Принято | Возможность восстановления |
| Архив досок отделён от корзины задач | Принято | Архив скрывает доску без удаления содержимого |
| Быстрое добавление отдельно от полного редактора | Принято | Сократить время фиксации задачи |
| Markdown preview без расширенной toolbar | Принято для MVP | Не усложнять редактор |
| Undo/Redo через SwiftData UndoManager | Принято | Использовать системную историю изменений |
| Иконка генерируется локально | Принято | Не зависеть от внешних бинарных ресурсов |
| GitHub Actions на macOS 26 | Принято | Проверка Swift-кода и app bundle |
| Source-only GitHub Releases | Принято | Публиковать исходники без обязательной цепочки Developer ID/notarization |

## Решения реализации

- Board, BoardColumn, TaskCard и TaskChecklistItem используют UUID.
- Порядок колонок и задач хранится через sortOrder.
- Checklist item связан с задачей через taskID.
- Удаление задачи переводит её в корзину; окончательное удаление удаляет и checklist items.
- Архивирование доски меняет isArchived, не удаляя её содержимое.
- Импорт создаёт новые UUID и добавляет доски к существующим.
- Настройки интерфейса хранятся отдельно от файла SwiftData Vault.
- Перенос Vault сохраняет исходную базу и активирует новую локацию после проверки целевой базы.

## Ограничения MVP

- Нет облака, аккаунтов, совместной работы и backend.
- Нет вложений и расширенной панели Markdown.
- Нет автоматических обновлений.
- Source-only GitHub Release не является готовым установщиком приложения.
- SwiftData integration tests не входят в текущий CI из-за нестабильного падения SwiftPM test runner (`signal 5`) при запуске экспериментальной suite.

## Открытые ручные проверки

- Проверка миграций и переноса Vault на реальном macOS.
- Проверка восстановления после принудительного завершения.
- Полный прогон Undo/Redo, импорт/экспорт и edge cases на живом хранилище.
- Полная проверка VoiceOver и keyboard-only навигации.

Сценарии и результаты фиксируются в checklist-документах. Не считать их пройденными только на основании CI.

## Канал релиза

Первая версия публикуется как GitHub Release с исходниками. Готовый app binary, Developer ID signing и notarization могут быть отдельной будущей задачей, если появится потребность распространять приложение среди других пользователей Mac.
