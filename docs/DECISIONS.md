# Решения и открытые вопросы

## Принятые решения

| Решение | Статус | Причина |
|---|---|---|
| Нативное приложение macOS | Принято | SwiftUI и точечный AppKit |
| Минимальная версия macOS 26 Tahoe | Принято | Современные API без поддержки старых систем |
| Локальное хранилище SwiftData | Принято | Системное решение Apple для persistence |
| Только локально, без синхронизации | Принято | Без аккаунтов, backend и сетевых зависимостей |
| Нативный стиль macOS | Принято | Системная навигация, типографика, меню и appearance |
| JSON-импорт добавляет копии | Принято | Не перезаписывать данные молча |
| Удаление колонки переносит карточки | Принято | Защита от случайной потери задач |
| Удаление доски/задачи подтверждается | Принято | Безопасные разрушительные действия |
| Метки хранятся строкой через запятую | Принято | Простая локальная модель для MVP |
| Чек-лист — отдельная SwiftData-модель | Принято | Независимое состояние и сортировка пунктов |
| Архив JSON обратно совместим с ранней схемой | Принято | Новые поля меток и чек-листа опциональны |

## Решения реализации

- Модели Board, BoardColumn, TaskCard и TaskChecklistItem используют UUID.
- После перемещения карточек и колонок порядок нормализуется от нуля.
- Метки разделяются запятыми; пустые значения и дубликаты без учёта регистра удаляются при отображении.
- Чек-лист хранит заголовок, состояние выполнения, порядок и taskID.
- Удаление задачи или доски удаляет связанные пункты чек-листа.
- Импорт создаёт новые UUID для всех сущностей и добавляет доски после уже существующих.
- Хранение не подключает CloudKit и не отправляет данные по сети.
