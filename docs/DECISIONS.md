# Решения и открытые вопросы

## Принятые решения

| Решение | Статус | Причина |
|---|---|---|
| Нативное приложение macOS | Принято | SwiftUI и точечный AppKit |
| Минимальная версия macOS 26 Tahoe | Принято | Современные API без поддержки старых систем |
| Локальное хранилище SwiftData | Принято | Системное решение Apple для persistence |
| Только локально, без синхронизации | Принято | MVP без аккаунтов, backend и сетевых зависимостей |
| Нативный стиль macOS | Принято | Системная навигация, типографика, меню и appearance |
| Личный Kanban сначала | Принято | Сначала быстрый и надёжный основной сценарий |
| Новая функция — отдельная ветка | Принято | Изолированный diff и ревью |
| Крупные законченные блоки | Принято | Меньше промежуточных коммитов и шума |
| JSON-импорт добавляет копии | Принято | Не перезаписывать пользовательские данные молча |
| Удаление колонки переносит карточки | Принято | Защита от случайной потери задач |
| Удаление доски/задачи подтверждается | Принято | Безопасные разрушительные действия |

## Решения реализации

- Модели Board, BoardColumn и TaskCard используют UUID и sortOrder.
- После перемещения карточек и колонок порядок нормализуется в диапазон от нуля.
- Перетаскивание использует нативные SwiftUI draggable и dropDestination.
- Архив JSON имеет поле formatVersion; первая поддерживаемая версия — 1.
- Импорт проверяет ссылки и названия, затем создаёт новые UUID для всех импортированных сущностей.
- Срок выполнения карточки необязательный.
- Ошибки операций показываются пользователю.
- Хранение не подключает CloudKit и не отправляет данные по сети.
