# Решения и открытые вопросы

## Принятые решения

| Решение | Статус | Причина |
|---|---|---|
| Нативное приложение macOS 26+ | Принято | SwiftUI и системные паттерны |
| Локальное хранилище SwiftData | Принято | Без аккаунтов и backend |
| JSON-импорт добавляет копии | Принято | Не перезаписывать данные молча |
| Удаление колонки переносит карточки | Принято | Защита от случайной потери задач |
| Удаление задачи сначала в корзину | Принято | Возможность восстановить случайно удалённое |
| Цвет метки вычисляется из текста | Принято | Стабильные цвета без отдельной таблицы настроек |
| Фильтр меток использует существующие метки доски | Принято | Не предлагать пустые фильтры и не требовать отдельного справочника |
| Окончательное удаление доступно только из корзины | Принято | Явное разделение мягкого и окончательного удаления |
| Метки хранятся строкой через запятую | Принято | Простая локальная модель для MVP |
| Чек-лист — отдельная SwiftData-модель | Принято | Независимое состояние и сортировка пунктов |
| Архив JSON обратно совместим с ранней схемой | Принято | Новые поля опциональны |
| Иконка генерируется локально | Принято | Не зависеть от внешних бинарных ресурсов |
| GitHub Actions на macOS 26 | Принято | Автоматическая проверка Swift-кода и app bundle |
| Релиз требует Developer ID и notarization | Принято | Подписанная доставка вне App Store |

## Решения реализации

- Модели Board, BoardColumn, TaskCard и TaskChecklistItem используют UUID.
- После перемещения карточек и колонок порядок нормализуется от нуля.
- Чек-лист хранит заголовок, состояние выполнения, порядок и taskID.
- Удаление задачи переносит её в корзину, не удаляя запись и checklist items.
- Импорт создаёт новые UUID для всех сущностей и добавляет доски после уже существующих.
- Хранение не подключает CloudKit и не отправляет данные по сети.
