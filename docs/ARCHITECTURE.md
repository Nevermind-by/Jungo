# Архитектура Jungo

> Статус: архитектура первой реализации. Реальные ограничения и решения обновляются вместе с кодом.

## Подтверждённые решения

- Платформа: macOS 26 Tahoe и новее.
- Язык/UI: Swift + SwiftUI; AppKit точечно для поведения, где это оправдано.
- Хранилище: SwiftData.
- Режим: local-first, без аккаунта, backend и синхронизации.
- Сборка текущего каркаса: Swift Package Manager; приложение запускается на macOS командой `swift run Jungo`. Подписываемый .app bundle и распространение — отдельная задача перед релизом.

## Слои

### Presentation
SwiftUI-экраны, навигация, состояния пустого контента, карточки и редактор задачи. UI не должен содержать правила сериализации и миграций.

### Domain
Модели доски, колонки и задачи, приоритеты и функции нормализации порядка. Доменная логика не должна зависеть от UI.

### Persistence
SwiftData `ModelContainer` и `ModelContext` обеспечивают локальное сохранение. Не включать CloudKit entitlement и не добавлять сетевые зависимости.

## Модели первой версии

- `Board`: идентификатор, название, порядок, дата создания.
- `BoardColumn`: идентификатор, название, порядок и идентификатор доски.
- `TaskCard`: идентификатор, заголовок, описание, приоритет, порядок, идентификатор колонки и дата создания.

Связи на первом этапе заданы через UUID, чтобы не привязывать логику порядка к сложному графу отношений. Перед добавлением удаления досок/колонок нужно определить каскадное поведение и тесты целостности.

## Запуск и начальные данные

При первом запуске создаётся доска «Моя доска», три колонки и несколько демонстрационных задач. Существующие данные не перезаписываются при следующих запусках.

## Текущие возможности каркаса

- Боковая панель с досками.
- Начальная Kanban-доска с тремя колонками.
- Создание доски и задач.
- Редактирование заголовка, описания и приоритета задачи.
- Поиск по заголовку и описанию.
- Перемещение задачи в другую колонку через контекстное меню.
- Удаление задачи.
- Сохранение в SwiftData.
- Светлая/тёмная тема следует системным настройкам macOS.

## Ограничения текущего блока

- Нет drag-and-drop.
- Нет редактирования и удаления колонок.
- Нет удаления доски.
- Перемещение карточек пока не предлагает полноценную перестановку внутри колонки.
- Ошибки сохранения требуют отдельного UX и не должны оставаться скрытыми в последующих блоках.
- Swift Package Manager executable — запускной каркас для разработки, но не готовый распространяемый .app.

## Проверки

Unit-тесты проверяют нормализацию порядка и ограничение позиции вставки. Сборку и тесты необходимо выполнять на macOS 26+ с установленным Swift 6 toolchain:
```bash
swift test
swift run Jungo
```
