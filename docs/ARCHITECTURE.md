# Архитектура Jungo

## Принятые решения

- Платформа: macOS 26 Tahoe и новее.
- UI: SwiftUI; AppKit используется для системных интеграций и управления окном.
- Глобальная горячая клавиша реализована через Carbon Event Manager без сторонних зависимостей.
- Хранилище: SwiftData; пользователь может выбрать локальную папку для активной базы через Settings.
- Режим: local-first, без аккаунта, backend и синхронизации.
- Сборка: Swift Package Manager executable target и скрипты упаковки .app.
- Иконка создаётся локальным Swift-скриптом.
- JSON-импорт добавляет новые доски, не заменяя текущие данные.

## Слои

### Presentation
`RootView` управляет выбранной доской, поиском, фильтрами, корзиной, диалогами и действиями пользователя. Карточки задач поддерживают drag-and-drop, клавиатурный фокус и accessibility-действия. Редактор задачи работает с черновиком и применяет изменения по сохранению. `QuickAddTaskSheet` вынесен в отдельный файл `Sources/Jungo/QuickAddTaskSheet.swift`; header и footer остаются видимыми, а форма прокручивается при ограниченной высоте окна.

### Domain
`JungoCore` содержит чистые функции сортировки, нормализации меток и проверки/кодирования архивов. `JungoArchiveImportPlan` заранее создаёт новые ID и переназначает связи между досками, колонками, задачами и пунктами чек-листа.

### Persistence
`VaultStore` создаёт SwiftData ModelContainer до открытия основного окна. При первом запуске используется стандартная конфигурация, при наличии security-scoped bookmark открывается база в выбранной папке. Недоступное сохранённое хранилище не должно молча заменяться пустой базой.

Перенос Vault копирует модели с исходными UUID в отдельный контейнер, проверяет целевую базу и только после этого активирует новую локацию. Существующий целевой `Jungo.store` не перезаписывается. JSON-экспорт остаётся отдельным способом резервного копирования.

Основной ModelContext использует UndoManager. Импорт работает в отдельном контексте без UndoManager, чтобы не смешивать импорт с незавершёнными изменениями UI. При ошибке импорта вызывается rollback изолированного контекста.

### Archive
`JungoArchiveDocument` задаёт Codable JSON-формат версии 1. Необязательные поля позволяют читать ранние архивы. Перед импортом проверяются версия, уникальность ID, ссылки и непустые названия. Импорт создаёт новые UUID и не перезаписывает существующие записи.

### Packaging and CI
- `Scripts/build-app.sh` собирает executable, генерирует AppIcon.icns, создаёт bundle metadata и подписывает локальную сборку ad-hoc.
- `Scripts/run-app.sh` собирает и открывает локальный .app.
- `Scripts/package-release.sh` — отдельный необязательный путь Developer ID signing/notarization; он не используется для текущего source-only GitHub Release.
- GitHub Actions на macOS 26 запускает unit-тесты, собирает development bundle и проверяет plist/иконку.

## Основные сценарии

- Drop на карточку вставляет задачу перед целью; drop на колонку перемещает задачу в конец.
- Поиск проверяет название, описание и метки; пустой запрос не должен скрывать задачи.
- Дублирование доски создаёт новые ID для связанных сущностей и копирует структуру.
- Дублирование задачи создаёт новый ID, копирует содержимое и сбрасывает отметки чек-листа.
- Удаление задачи отправляет её в корзину; восстановление возвращает в исходную колонку.
- Удаление колонки переносит задачи в первую оставшуюся колонку.
- Архивирование доски скрывает её из активного списка, сохраняя содержимое.
- Импорт JSON добавляет копии досок и выбирает последнюю импортированную доску.
- Выбранная доска и UI-настройки хранятся локально отдельно от JSON-архива.
- Быстрое добавление доступно из меню-бар, глобально через Cmd+Option+Space и внутри приложения через Cmd+Option+N.

## Проверки

```bash
swift test
swift run Jungo
Scripts/build-app.sh
Scripts/run-app.sh
```

CI подтверждает тесты и сборку bundle. Интерактивные сценарии SwiftData, миграции, VoiceOver и перенос Vault требуют ручной проверки на macOS 26+.

## Ограничения

- Нет облака, совместной работы и аккаунтов.
- Прямые SwiftData integration tests не входят в текущий SwiftPM test target: экспериментальная suite падала с `signal 5`.
- Notarized binary distribution не входит в текущий source-only релиз.
