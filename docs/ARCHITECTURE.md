# Архитектура Jungo

## Принятые решения

- Платформа: macOS 26 Tahoe и новее.
- UI: SwiftUI; AppKit используется для системных диалогов и генерации ресурсов приложения.
- Хранилище: SwiftData.
- Режим: local-first, без аккаунта, backend и синхронизации.
- Сборка: Swift Package Manager executable target и скрипты упаковки .app.
- Иконка создаётся локальным Swift-скриптом и iconutil; внешний binary asset не нужен.
- JSON-импорт добавляет новые доски, а не заменяет текущие данные.

## Слои

### Presentation
RootView управляет выбранной доской, фильтрами, корзиной, диалогами и действиями пользователя. TaskCardView показывает карточку и метки. TaskEditorSheet редактирует содержимое, сроки, метки и чек-лист.

### Domain
JungoCore содержит чистые функции TaskOrdering и TaskLabels. Перестановка и нормализация меток не зависят от SwiftUI и SwiftData и покрываются unit-тестами.

### Persistence
SwiftData ModelContainer и ModelContext обеспечивают локальное сохранение. Модели Board, BoardColumn и TaskCard используют UUID и целочисленный sortOrder. TaskChecklistItem ссылается на задачу через taskID. Срок задачи необязательный, метки хранятся строкой и нормализуются при отображении. TaskCard.isInTrash позволяет восстанавливать задачу до окончательного удаления.

### Archive
JungoArchive сериализует доски, колонки, задачи и пункты чек-листа в JSON формата версии 1. Дополнительные поля меток, корзины и чек-листа опциональны при декодировании для совместимости с ранними архивами. Перед импортом проверяются версия формата, уникальность ID, ссылки между сущностями и непустые названия. Импорт создаёт новые UUID и новые доски.

### Packaging and CI
Scripts/build-app.sh собирает release executable, генерирует AppIcon.icns, создаёт bundle metadata и подписывает локальную сборку ad-hoc. Scripts/package-release.sh выполняет Developer ID signing, notarization и staple при наличии настроенных учётных данных. GitHub Actions workflow на macOS 26 запускает unit-тесты, собирает bundle и проверяет plist/иконку.

## Основные сценарии

- Перетаскивание карточки на другую карточку вставляет её перед целью; drop на область колонки перемещает в конец.
- Удаление задачи отправляет её в корзину; восстановление возвращает в исходную колонку. Окончательное удаление из корзины удаляет и пункты чек-листа.
- Удаление колонки переносит задачи в первую оставшуюся колонку; последнюю колонку удалить нельзя.
- Удаление доски требует подтверждения и удаляет связанные задачи и пункты чек-листа.
- Импорт архива — добавление копии данных, а не замена или синхронизация.
- Выбранная доска хранится локально через AppStorage.

## Проверки

    swift test
    swift run Jungo
    Scripts/build-app.sh
    Scripts/run-app.sh

Unit-тесты покрывают порядок и разбор меток. UI, SwiftData schema migration, генерация иконки и bundle требуют проверки на macOS 26+.

## Ограничения

- Нет облака, совместной работы и аккаунтов.
- Notarized-релиз требует действующих Developer ID и notarytool credentials.
- Перед выпуском нужно проверить VoiceOver, клавиатурную навигацию, большие архивы и восстановление после аварийного завершения.
