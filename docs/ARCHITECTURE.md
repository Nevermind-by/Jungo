# Архитектура Jungo

## Принятые решения

- Платформа: macOS 26 Tahoe и новее.
- UI: SwiftUI; AppKit точечно для системных диалогов файлов.
- Хранилище: SwiftData.
- Режим: local-first, без аккаунта, backend и синхронизации.
- Сборка: Swift Package Manager executable target для разработки; .app packaging и подпись — релизный этап.
- Импорт JSON добавляет новые доски, а не заменяет текущие данные.

## Слои

### Presentation
RootView управляет выбранной доской, фильтрами, диалогами и действиями пользователя. TaskCardView и редактор карточки отвечают за представление. Ошибки операций показываются пользователю через alert.

### Domain
JungoCore/TaskOrdering.swift содержит чистые функции перестановки и переноса между коллекциями. Функции не зависят от SwiftUI и SwiftData и тестируются отдельно.

### Persistence
SwiftData ModelContainer и ModelContext обеспечивают локальное сохранение. Модели Board, BoardColumn и TaskCard используют UUID-идентификаторы и целочисленный sortOrder. После операций перестановки порядок нормализуется в последовательность 0...n-1. У карточки есть необязательный срок выполнения.

### Archive
JungoArchive сериализует доски, колонки и задачи в JSON формата версии 1. Перед импортом проверяются версия формата, уникальность идентификаторов, ссылки между сущностями и непустые названия. Импорт создаёт новые UUID и новые доски, сохраняя существующее содержимое.

## Основные сценарии

- Перетаскивание карточки на другую карточку вставляет её перед целью.
- Перетаскивание на свободное место колонки помещает карточку в конец.
- Удаление колонки переносит её задачи в первую оставшуюся колонку этой доски; последнюю колонку удалить нельзя.
- Удаление доски требует подтверждения и удаляет связанные колонки и задачи.
- Удаление задачи требует подтверждения.
- Импорт архива не является заменой или синхронизацией; это безопасное добавление копии данных.
- Экспорт использует NSSavePanel, импорт — NSOpenPanel.

## Проверки

    swift test
    swift run Jungo

Unit-тесты покрывают границы вставки, перестановку внутри коллекции, перенос между коллекциями и перенос в пустую коллекцию. SwiftData и UI-поведение требуют запуска на macOS 26+.

## Ограничения

- Нет облака и синхронизации по принятому решению.
- Нет совместной работы и аккаунтов.
- .app упаковка, подпись/нотаризация и релизный pipeline остаются отдельным этапом.
- Перед выпуском нужно проверить VoiceOver, клавиатурную навигацию, импорт больших архивов и восстановление после аварийного завершения.
