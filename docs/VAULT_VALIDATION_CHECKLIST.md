# Проверка Vault Jungo

Этот checklist предназначен для ручной проверки переноса и восстановления доступа к SwiftData Vault на реальном macOS. Наличие файла Jungo.store само по себе не доказывает корректность хранилища: важны открытие через SwiftData, целостность записей и повторный запуск приложения.

## Статус

- Проверка кода Vault и unit-level валидация архива выполняются отдельно от этого checklist.
- GitHub Actions не запускает интерактивные сценарии файлового доступа и security-scoped bookmarks.
- Все пункты ниже остаются открытыми до выполнения на реальном Mac.

## Подготовка

- [ ] Создать резервную копию через JSON export и отдельно скопировать исходную базу при необходимости.
- [ ] Записать версию macOS, commit Jungo и расположение текущего Vault.
- [ ] Подготовить тестовую базу с несколькими досками, колонками, задачами, метками, сроками, приоритетами, чек-листами, архивом и корзиной.
- [ ] Зафиксировать количество записей каждого типа и их связи.

## Успешный перенос

- [ ] Выбрать пустую целевую папку и подтвердить перенос.
- [ ] Дождаться завершения проверки целевого хранилища.
- [ ] Перезапустить Jungo.
- [ ] Убедиться, что открылась новая база и все данные на месте.
- [ ] Сравнить количество сущностей, UUID и связи до/после.
- [ ] Убедиться, что исходная база осталась на прежнем месте.
- [ ] Создать и изменить задачу в новом Vault, перезапустить приложение и проверить сохранение.
- [ ] Проверить «Открыть в Finder»: открывается папка активного Vault.

## Негативные сценарии и восстановление

- [ ] Выбрать папку с существующим Jungo.store: перенос останавливается, данные не перезаписываются.
- [ ] Выбрать папку с SQLite sidecar-файлами без Jungo.store: перенос останавливается, sidecar не удаляется.
- [ ] Отменить подтверждение: перенос не начинается и настройки не меняются.
- [ ] Выбрать недоступную папку или отключить внешний диск: приложение показывает ошибку, не открывая пустую базу.
- [ ] Проверить, что экран ошибки показывает сохранённый путь.
- [ ] Восстановить диск и повторно запустить приложение.
- [ ] Выбрать папку без Jungo.store при восстановлении доступа: переключения не происходит.
- [ ] Выбрать повреждённый или пустой Jungo.store: он не становится активным.
- [ ] Проверить путь с пробелами и нелатинскими символами.
- [ ] Проверить внешний диск после извлечения и повторного подключения.
- [ ] Проверить освобождение старого и повторное получение нового security-scoped доступа.

## UI и регрессия

- [ ] Проверить перенос базы с большим количеством задач и пунктов чек-листа.
- [ ] Проверить клавиатуру, VoiceOver, диалоги подтверждения и ошибки.
- [ ] Убедиться, что сохранённые фильтры и пользовательские цвета меток остались на месте.
- [ ] После переноса проверить создание, редактирование, дублирование, перемещение, архивирование и удаление.
- [ ] Проверить JSON import/export и Undo/Redo.

## Результат

Записать версию macOS, версию/build Jungo, исходный и целевой путь, количество сущностей до/после, Pass/Fail и ссылки на доказательства. Не считать перенос проверенным только по наличию файла: обязательны повторный запуск приложения и сверка данных.
