## 0.1.0 — MVP

Первый публичный исходный релиз Jungo. Релиз содержит исходный код; готовый бинарный установщик не прикладывается.

### Возможности

- Локальный Kanban для macOS 26+ на SwiftUI и SwiftData.
- Несколько досок, архивирование, восстановление и дублирование структуры.
- Колонки и карточки с порядком, приоритетами, сроками, метками и чек-листами.
- Markdown-описания с отдельным режимом предпросмотра.
- Drag-and-drop между колонками и внутри колонки.
- Поиск, фильтры и сохранённые фильтры.
- Корзина задач с восстановлением и окончательным удалением.
- Быстрое добавление, меню-бар и глобальная горячая клавиша.
- Системные Undo/Redo для изменений SwiftData.
- JSON-экспорт и импорт дополнительных досок.
- Локальный Vault с переносом базы и проверками целостности.
- Нативная адаптивная дизайн-система с учётом системных тем и настроек доступности.

### Надёжность

- Валидация JSON-архива до передачи данных в слой хранения.
- Совместимость с ранними JSON-архивами без новых необязательных полей.
- Предварительное построение import plan с переназначением ID и внутренних связей.
- Изолированный SwiftData-контекст для импорта и rollback при ошибке.
- Проверка существующего Vault перед восстановлением доступа.
- Защита скрипта сборки от перезаписи произвольных директорий, symlink и чужих app bundles.
- Исправлена компоновка Quick Add: закреплённые header/footer, прокручиваемая форма, согласованные размеры и выравнивание.

### Проверки

- GitHub Actions на macOS 26: unit-тесты, сборка development app bundle и проверка метаданных/иконки.
- CI для последнего функционального изменения Quick Add: [run #186](https://github.com/Nevermind-by/Jungo/actions/runs/41058799530) — успешно.
- Quick Add проверен пользователем после локального запуска.

### Известные ограничения

- CI не подтверждает интерактивные сценарии SwiftData, миграции, перенос/восстановление Vault, VoiceOver и восстановление после аварийного завершения.
- Прямые SwiftData integration tests не включены: экспериментальный запуск suite в SwiftPM test runner завершался с `signal 5`.
- Ручные сценарии, которые ещё не выполнены, остаются открытыми в [чек-листе целостности данных](docs/DATA_INTEGRITY_CHECKLIST.md) и [чек-листе Vault](docs/VAULT_VALIDATION_CHECKLIST.md).
- Вложения и расширенная Markdown-панель не входят в MVP.
- GitHub Release публикует исходный код. Notarized app binary не входит в этот релиз.
